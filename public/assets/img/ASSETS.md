# Iron Meridian — Asset Manifest

All images in this directory are **original artwork generated for this project**
(AI-generated from original prompts; no third-party game art, screenshots or
branding was used as reference). Files are JPEG (no alpha needed; unit icons are
drawn on a dark plate that matches the game's token style).

| File | Role | Where it is used |
| --- | --- | --- |

| `campaign-map.jpg` | Strategic map banner of the (fictional) continent | Campaign screen header |
| `emblem-astria.jpg` | Astrian Federation (player faction) emblem | Menu, victory result, favicon |
| `emblem-karsia.jpg` | Karsite Union (enemy faction) emblem | Menu, defeat result |
| `terrain-plains.jpg` | Plains tile texture | Battlefield tiles |

## Generation & regeneration

- Generated by `scripts/gen-assets.mjs` (`bun run assets`) with per-asset
  prompts and art-direction constants; resized/compressed with `sharp`.
- Regenerate a single asset: `bun run scripts/gen-assets.mjs --only terrain-city`

## Fallbacks

If an image fails to load at runtime, components fall back to theme-token
color blocks (`AssetImage`) or terrain color fills (tiles). Fallbacks are a
safety net — the finished game ships with all assets above present and wired in.
